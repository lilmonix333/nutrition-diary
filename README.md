营养日记是一个不需要注册、不联网也能用的饮食与训练记录工具。

饮食侧内置 346 种常见食物（含家常菜、外卖、便利食品），按每 100g 算热量与蛋白、碳水、脂肪、纤维，配合 BMR/TDEE 给出减脂、维持、增肌三套目标，今日页实时显示还差多少、缺口该吃什么。

训练侧提供 7 套分化（二分化到五分化），每天列出推荐动作和组次，21 条核实过的 B 站跟练视频直链，另有 22 条补剂与动作要点小知识。

打卡得代币，可解锁 4 个小游戏（乒乓、打地鼠、单词拼写、刮刮乐）的永久加成。所有数据保存在浏览器本地，不上传任何服务器。

## 功能清单

### 一、饮食记录

- **346 条食物库**：主食 47 / 蛋白 74 / 蔬菜 49 / 水果 36 / 坚果油脂 21 / 家常菜 72 / 饮品零食 47
- 中文名与全拼搜索（`jixiong` → 鸡胸肉）
- 份量快捷选择 ＋ 克数步进 ＋ 实时营养预览
- **自定义食物**：填一次每 100g 营养，长期可用
- **收藏**：食物行点 ☆，单独一栏快速调用
- **一键复制昨天**：减脂期天天吃一样，省一半操作
- **缺口提示**：「蛋白还差 62g ≈ 鸡胸肉 260g 或希腊酸奶 624g」

### 二、营养计算

- BMR 用 Mifflin-St Jeor，TDEE = BMR × 活动系数（1.2–1.9）
- 目标热量按减脂 −20% / 维持 / 增肌 +12% 调整，带 `max(BMR×1.1, 1200)` 安全下限
- 蛋白按体重给（1.5–1.8 g/kg），脂肪按供能比，碳水补足余量
- 膳食纤维 25–40g、饮水按体重 ×35 ml

### 三、训练

- **7 套分化预设**：二分化·上下肢、三分化·推拉腿、三分化·背胸腿、四分化·胸背腿肩、五分化·经典、五分化·分化版、全身 A/B
- 选完分化立即给出「这套分化的安排」（逐日）和「今日推荐动作」
- **37 个动作**带组数次数（杠铃卧推 4×6-8、引体向上 4×力竭、平板支撑 3×40 秒…）
- 每日部位是可增删的 tag，改完动作清单跟着变
- **21 条 B 站跟练视频直链**，覆盖全部 9 个部位，标了 UP 主 / 时长 / 播放量
- 支持自己添加视频、替换内置条目、删除自定义条目
- **22 条小知识**：补剂 7、动作要点 8、饮食 4、恢复 3

### 四、打卡与代币

- 每日打卡 +10，连续两天 +15
- 周目标按档案自动生成（如「5 次训练 / 日均 2130 kcal / 蛋白 ≥120g / 体重降 0.3–0.7kg」）
- 达成周目标一次 +100

### 五、小游戏（训练间歇 1–2 分钟）

| 游戏 | 玩法 | 时长 |
|---|---|---|
| 电子乒乓 | 拖动控制球拍，球速越打越快 | 90 秒 |
| 打地鼠 | 3×3 地鼠，连中 3 只有金色加分 | 30 秒 |
| 单词拼写 | 1539 词，看中文填挖空的字母（首字母保留） | 90 秒 |
| 刮刮乐 | 6×6 格埋 12 组三连，刮出三个相同数字即结算 | 单张即开 |

**场外商店**：7 个永久加成，按游戏标注（🏓 乒乓 / 🐹 打地鼠 / 🔤 单词 / 🎟️ 刮刮乐）。加成只提高容错（板子更长、多一条命、少挖几个空），核心难度不消失。

### 六、报告

- 近 7 / 30 天热量柱状图，带目标虚线
- 记录日均、热量达标率（±10%）、蛋白达标率（≥90%）
- 三大营养素供能比 vs 建议值
- 餐次热量分布、最常吃 Top5、连续记录天数、本周 vs 上周日均对比
- 体重迷你折线图 ＋ 自动生成的饮食建议

### 七、外观与数据

- 深色 / 浅色 / 跟随系统
- 6 套强调色，环形进度弧与图表联动变色
- 6 套背景皮肤（深浅各一套）＋ 自定义背景图（压到 1200px）
- **卡片不透明度**四档：不透明 / 轻微 / 半透 / 很透
- **背景固定层**：背景不随页面滚动（iOS 也不掉帧）
- 导出 / 导入完整备份（档案、记录、饮水、体重、自定义食物、收藏、视频绑定、训练计划、答题进度）
- 脏数据导入逐字段校验，存储损坏先留底再回退

## 边界

- 数据存 `localStorage`，**按域名隔离**：换网址、换浏览器、换手机不会自动同步，靠「导出备份」迁移
- 食物营养值为成分表估算，烹饪油量差异会让实际值浮动
- 训练视频是外部 B 站内容，可能被删除；`tools/check_bili.py` 可批量体检
- 不提供医疗诊断、处方或药物建议
